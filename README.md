Glitch Dimension

This is an Electrol art project made it using HTML, CSS, and JavaScript.
In this project the screen flickers and it glitches in a black-background with some floating geometrical shapes, moving lines etc. When you click on the screen , it triggers glitch effect that makes visuals distort and screen looks like its lagging.

Features
 Dark background with neon colors.
 Floating geometrical objects.
 Different types of animations.
 RGB color distortion an screen flickering.

 How to Run 

 Download or clone this repository.
 open project folder
 open html in your browser 
 Then enjoy the glitch effect
